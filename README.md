# Xbox Audio Bridge

App Android que recebe só o áudio do Xbox pela rede (streaming local xHome) e toca no celular.
Feito por CyberSaturnX.

- Login Xbox dentro do app, botão grande para conectar, controle de volume.
- Atualização pelo próprio app (busca a release "latest" deste repositório).
- A cada push na `main`, o GitHub Actions compila o APK assinado com chave fixa e publica em Releases > latest.
